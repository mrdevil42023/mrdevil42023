# ⚡ Kailash - Animated Web Portfolio

This is an exact single-page web portfolio implementation of your original GitHub profile README, enhanced with **dynamic scroll-driven animations** (scrolling down or scrolling up triggers smooth animations on every section).

---

## 📁 File Structure
- `index.html` — Original README layout & badges structured in semantic HTML5.
- `style.css` — Ultra-sleek dark/crimson theme (`#050505`, `#8B0000`, `#FF2020`) with CSS keyframes & glow effects.
- `script.js` — Lightweight `IntersectionObserver` scroll listener that re-triggers animations whenever elements enter or leave the viewport.

---

## 🚀 How to View & Test Locally

1. Simply double-click `index.html` to open it in your web browser.
2. Scroll up and down to see the skills, stats, titles, and dividers smoothly animate in and out as you scroll!

---

## 🌐 Deploying to GitHub Pages (Free Hosting)

1. Create a repository named `kailash-portfolio` (or `mrdevil42023.github.io`).
2. Push `index.html`, `style.css`, and `script.js` to the repository.
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Select `main` branch and click **Save**.
5. Your animated portfolio will be live at `https://mrdevil42023.github.io/`!
